# Como contribuir

1. Atualize a `development` local: `git checkout development && git pull`
2. Crie sua branch: `git checkout -b feature/<nome-da-feature>`
3. Faça commits pequenos e semânticos
4. Suba a branch e abra um Pull Request para a `development`

## Padrão de commits semânticos

| Tipo       | Uso                                         |
|------------|---------------------------------------------|
| `feat`     | nova funcionalidade                         |
| `fix`      | correção de bug                             |
| `docs`     | alteração em documentação                   |
| `style`    | formatação, espaços, sem mudança de lógica  |
| `refactor` | reestruturação de código sem mudar comportamento |
| `test`     | criação ou ajuste de testes                 |
| `chore`    | tarefas de manutenção e configuração        |

Exemplo: `docs: adiciona seção sobre o fluxo Git Flow no README`
