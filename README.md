## Fluxo de trabalho (Git Flow)

- `main`: versão em produção
- `release`: versão em homologação, preparada para ir para a `main`
- `development`: integração das features da equipe
- `feature/*`: uma branch por integrante/funcionalidade, criada a partir da `development`
